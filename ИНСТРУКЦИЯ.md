# Что делать с проектом — пошагово

Это сайт вашей книги: страница книги, ридер со сменой музыки и фона по сценам, админка.
Ниже — два пути:

- **Путь А** — сначала запустить у себя на компьютере и посмотреть (рекомендую).
- **Путь Б** — сразу выложить в интернет через Railway.

> ⚠️ Проект ещё ни разу не запускался (на компьютере, где его писали, не было Node.js).
> Возможны мелкие ошибки при первом запуске. Если что-то пошло не так —
> скопируйте текст ошибки и пришлите мне, я поправлю.

---

## Шаг 0. Распаковать архив

1. Нажмите правой кнопкой по `book-reader.zip` → **Извлечь всё…** → **Извлечь**.
2. Лучше распаковать **не на Рабочий стол в OneDrive**, а, например, в `C:\Projects\book-reader`
   (OneDrive начинает синхронизировать тысячи служебных файлов и всё тормозит).

## Путь А. Запуск на своём компьютере

### А1. Установить программы (один раз)

1. **Node.js** — https://nodejs.org → большая зелёная кнопка **LTS** (версия 22) → скачать → установить, везде «Далее».
2. **Docker Desktop** — https://www.docker.com/products/docker-desktop → Download for Windows → установить → перезагрузить компьютер → запустить Docker Desktop и дождаться зелёной надписи *Engine running*.
   Docker нужен только чтобы локально запустить базу данных PostgreSQL.

Проверка: откройте **PowerShell** (Пуск → напечатать `PowerShell`) и введите:

```powershell
node -v
```

Должно показать что-то вроде `v22.x.x`.

### А2. Открыть папку проекта в PowerShell

Откройте папку `book-reader` в Проводнике → кликните по адресной строке сверху →
напечатайте `powershell` → Enter. Откроется PowerShell уже в этой папке.

### А3. Установить зависимости

```powershell
npm install
```

Займёт 1–3 минуты. Предупреждения (`WARN`) — нормально. Если в конце красное `ERR!` — пришлите мне текст.

### А4. Настроить файл `.env`

```powershell
Copy-Item .env.example .env
```

Сгенерируйте секретный ключ:

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

Скопируйте получившуюся строку. Откройте файл `.env` Блокнотом и заполните:

```
JWT_SECRET=сюда_вставьте_строку_из_команды_выше
ADMIN_USERNAME=admin
ADMIN_PASSWORD=придумайте_пароль_минимум_10_символов
```

Сохраните файл.

### А5. Запустить базу данных

(Docker Desktop должен быть открыт.)

```powershell
docker compose up -d db
```

### А6. Создать таблицы и демо-книгу

```powershell
npx prisma migrate deploy
npm run db:seed
```

Во второй команде должно написать `[seed] Done: 3 chapters...`.

### А7. Проверить код на ошибки

```powershell
npm run typecheck
```

Если ничего не написало — отлично. Если есть ошибки — пришлите их мне целиком.

### А8. Запустить сайт

```powershell
npm run dev
```

Откройте в браузере:

- **http://localhost:5173** — сайт книги
- **http://localhost:5173/admin** — админка (логин и пароль из `.env`)

Откройте главу 3 «Битва» и прокрутите — фон и музыка должны меняться по сценам.

Остановить сайт: в окне PowerShell нажмите **Ctrl + C**.
В следующий раз достаточно: открыть Docker Desktop → `docker compose up -d db` → `npm run dev`.

## Путь Б. Выложить в интернет (Railway)

### Б1. Загрузить проект на GitHub

1. Зарегистрируйтесь на https://github.com.
2. Проще всего — программа **GitHub Desktop** (https://desktop.github.com):
   File → **Add local repository** → выберите папку `book-reader` → она предложит
   *create a repository* → **Create repository** → **Publish repository**
   (галочку *Keep this code private* можно оставить).
   Файл `.env` с паролями на GitHub **не попадёт** — он в списке исключений, так и должно быть.

### Б2. Создать проект на Railway

1. Зайдите на https://railway.com → войдите через GitHub.
2. **New Project** → **Deploy from GitHub repo** → выберите `book-reader`.
3. В том же проекте: **+ Create** → **Database** → **PostgreSQL**.

### Б3. Переменные

Откройте сервис сайта (не базу) → вкладка **Variables** → добавьте:

| Имя | Значение |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `JWT_SECRET` | длинная случайная строка (как в шаге А4) |
| `ADMIN_USERNAME` | `admin` |
| `ADMIN_PASSWORD` | ваш пароль (минимум 10 символов) |
| `SEED_DEMO` | `true` — если хотите демо-книгу для проверки |

### Б4. Хранилище для музыки и картинок (обязательно!)

Сервис сайта → **Settings** → **Volumes** → **+ New Volume** → Mount path: `/data`.

Без этого загруженные MP3 и картинки будут **пропадать** при каждом обновлении сайта.

### Б5. Получить адрес сайта

Сервис сайта → **Settings** → **Networking** → **Generate Domain**.
Откройте адрес — это ваш сайт. Админка — адрес + `/admin`.

Если сборка упала (красный крестик в Deployments) — откройте его, нажмите **View logs**,
скопируйте ошибку и пришлите мне.

## Как наполнять книгу (админка)

1. **Книга** (вкладка вверху) — название, автор, описание, обложка, строки карточки («Тип», «Статус»…).
2. **Медиатека** — загрузите музыку (MP3) и картинки для фонов. Можно перетащить файлы мышкой.
3. **Главы** → **+ Новая**:
   - впишите название, номер главы, том;
   - текст пишется внутри **сцен**. У каждой сцены раскройте **«Атмосфера»**:
     - **Музыка**: «Продолжить» (играет то же, что раньше), «Трек» (выбрать MP3), «Тишина»;
     - **Фон**: цвет/градиент или картинка из медиатеки;
     - **Длительность перехода** — как плавно меняется (1–2 секунды обычно лучше всего);
   - **+ Добавить сцену** — новая сцена ниже. Когда читатель до неё докрутит — сменится музыка и фон;
   - **Сохранить** (или Ctrl+S);
   - **Предпросмотр** — посмотреть, как увидит читатель;
   - переключатель **Опубликована** — глава появится у читателей.
4. Если включали `SEED_DEMO=true` — демо-главы можно удалить кнопкой «Удалить главу».

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| `node` не найден | Переустановите Node.js и **закройте/откройте** PowerShell заново |
| `docker` не найден / ошибка подключения | Откройте Docker Desktop и дождитесь *Engine running* |
| `Invalid environment configuration` | Проверьте `.env`: `JWT_SECRET` ≥ 32 символов, `ADMIN_PASSWORD` ≥ 10 |
| Не пускает в админку | Логин/пароль из `.env`. Сменить пароль: поставить новый `ADMIN_PASSWORD` и `ADMIN_RESET_PASSWORD=true`, перезапустить, потом убрать `ADMIN_RESET_PASSWORD` |
| Нет музыки | Нажмите в любом месте страницы — браузеры включают звук только после действия пользователя. Проверьте значок 🔊 в ридере |
| Любая другая ошибка | Скопируйте текст ошибки целиком и пришлите мне |

Подробное техническое описание (API, архитектура, безопасность) — в файле `README.md`.
